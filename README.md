🎧 Audio Files

Audio files must be placed inside the "assets" folder.

Example:

assets/song1.mp3
assets/song2.mp3
assets/song3.mp3

The filename in "script.js" must match the actual filename.

Example:

audio: "assets/song1.mp3"

means the file must exist at:

assets/song1.mp3

👁️ Eye Animation

The eye is generated using JavaScript and HTML Canvas.

No eye video is required.

The animation includes:

- Eye opening
- Eye closing
- Natural blinking
- Iris movement
- Pupil movement
- Eye reflection
- Neon glow
- Cinematic zoom
- Scanline effect

The eye animation runs automatically in the browser.

---

📝 Lyrics

Lyrics are synchronized with the selected audio.

Lyrics are defined inside "script.js".

Example:

lyrics: [
    {
        time: 0,
        text: "FIRST LINE"
    },

    {
        time: 5,
        text: "SECOND LINE"
    },

    {
        time: 10,
        text: "THIRD LINE"
    }
]

The "time" value is in seconds.

When the audio reaches that time, the corresponding lyric appears.

Only use lyrics that you have permission to publish.
